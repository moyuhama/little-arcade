# 摸鱼街机

游戏大厅 + 独立小游戏页面，纯 HTML/CSS/JavaScript，无需安装或构建。

在线地址：https://moyuhama.github.io/little-arcade/

## 本地预览

在本目录执行 `python3 -m http.server 4173`，然后打开 `http://localhost:4173/`。

## 新增游戏

1. 在 `games/游戏英文名/` 新建游戏页面与资源，例如 `games/snake/index.html`。
2. 在 `catalog.js` 的清单中追加一条记录，确保 `id` 唯一：

```js
{
  id: 'snake',
  title: '贪吃蛇',
  description: '控制方向，吃到食物，让小蛇慢慢长大。',
  category: '街机',
  tags: ['单人', '反应'],
  keywords: ['snake', '蛇'],
  url: './games/snake/index.html',
  addedAt: '2026-10-24',
  cover: './games/snake/cover.png' // 可选，没有封面时自动显示游戏名称
}
```

3. 在新游戏 HTML 的 `<head>` 中加入：

```html
<script defer src="../../lobby.js" data-game-id="snake"></script>
```

4. 将修改提交到 GitHub 的 `main` 分支。Pages 从根目录自动发布。

请先完成游戏页面，再登记到清单。首页会自动生成游戏卡片、分类、数量与搜索结果，无需手动修改首页。

## 功能与文件

- `index.html`：游戏大厅结构。
- `hall.css`：大厅专用响应式样式。
- `catalog.js`：已上线游戏的统一清单。
- `lobby.js`：搜索、分类、排序、收藏、最近玩过和游玩记录。
- `style.css`：共享样式及 2048 页面样式。
- `game-shell.css` / `game-shell.js`：八款游戏共用的紧凑布局、返回/暂停或撤销/重开/玩法工具栏、玩法弹窗与游戏切换栏。棋盘按可用窗口高度缩放；实时游戏打开玩法时自动暂停。
- `games/2048/`：2048 游戏，支持方向键/WASD、手机滑动、撤销、自动保存。
- `games/snake/`：贪吃蛇，支持三档速度、方向键/WASD、手机滑动与方向按钮、暂停和重新开始。空格暂停/继续，Escape 暂停；切换窗口或页面进入后台时自动暂停，手动继续后才会移动。
- `games/minesweeper/`：扫雷，9×9 / 12×12 / 16×16 三档难度，首点及周围八格安全，右键或手机插旗模式，点击数字展开邻格，暂停计时与本档最快纪录。大棋盘可在棋盘区域内滚动；方向键移动焦点，Enter/空格挖开，F 插旗。
- `games/breakout/`：打砖块，三关布局、三条生命、角度反弹，支持鼠标、触屏拖动、方向键/A/D 与手机方向按钮；空格发球/暂停/继续。最高分本地保存。
- `games/tetris/`：俄罗斯方块，七种形状分组打乱出现、下一块与落点预览、消行计分和每 10 行升级。左右移动，上键旋转，下键加速，空格直落，P / Escape 暂停；手机提供可长按的方向按钮。落地后有 500ms 调整时间，移动或旋转最多重置 15 次。
- `games/sokoban/`：推箱子，10 个自制且验证可解的关卡，可自由选关、逐步撤销、保存当前进度与每关最佳步数。方向键/WASD/滑动/方向按钮移动，Z 撤销；切换关卡从该关起点开始。
- `games/memory/`：记忆翻牌，6 / 8 / 12 对三档，每翻开两张计一次，配错后短暂停留并翻回。首张翻开后计时；暂停会隐藏卡牌并保留翻回倒计时。纪录先比较次数，再比较用时。
- `games/tictactoe/`：井字棋，轻松/认真两档人机对战、先后手选择和同屏双人。认真模式使用完整博弈搜索；人机悔棋撤回一轮，双人悔一步，撤销终局会一并撤销该局战绩。模式、难度、执子分别计战绩。

贪吃蛇每颗果子加 10 分，碰墙或碰到身体结束，不能直接反向掉头。各速度的最高分与上次选择的速度保存在独立的 `little-arcade-snake-v1` 浏览器存储中；刷新会重新开局。浏览器存储不可用时仍能正常游玩，最高分仅在当前页面有效。

收藏与最近 12 款游玩记录保存在当前浏览器，不跨设备同步。浏览器禁用存储时，大厅仍可搜索与筛选，收藏仅在当前页面有效。2048 的进度与最高分使用原有独立存储，不受大厅更新影响。

扫雷最快用时使用 `little-arcade-minesweeper-v1`，打砖块最高分使用 `little-arcade-breakout-best-v1`。这两款游戏刷新后重新开局，纪录保留；存储不可用时可正常游玩。扫雷暂停会隐藏棋盘并停止计时；实时游戏离开窗口后手动继续，避免后台意外结束。

俄罗斯方块最高分使用 `little-arcade-tetris-best-v1`，刷新后重新开局。推箱子使用 `little-arcade-sokoban-v1` 保存当前关卡、有效移动序列和各关最佳步数；刷新时通过重放合法移动恢复棋盘与撤销历史。

记忆翻牌的难度与各档最佳纪录使用 `little-arcade-memory-v1`；井字棋的设置与战绩使用 `little-arcade-tictactoe-v1`。这两款刷新后重新开局，已有纪录保留。所有游戏均无需后端或外部依赖。

## GitHub Pages 设置

Settings → Pages → Source：Deploy from a branch → main → / (root)。之后每次提交自动发布；本项目无需额外构建工作流。

## 规则测试

安装 Node.js 后执行 `node --test tests/*.test.js`。测试覆盖各游戏规则与边界、推箱子的全部关卡解法、翻牌输入锁定、井字棋电脑对手不败路径，以及八款游戏的资源路径、大厅筛选与工具栏接入；无需安装依赖。
