记忆翻牌怎么玩

  1. 每次翻开两张卡牌。相同图案会保持正面，不同图案会在短暂停留后翻回去。配齐所有卡牌就完成。
  2. 每翻完两张算一次；重复点击同一张、已经配好的卡牌不计次数。第一张翻开后开始计时。
  3. 有 6 对、8 对、12 对三档。最佳纪录先比较翻牌次数，次数相同再比较用时。
  4. 暂停、切换窗口或查看玩法时会隐藏卡牌并停止计时，回来后手动继续。重开后可以切换难度。
  5. 方向键移动焦点，Enter / 空格翻牌；手机直接点击卡牌。
